# React Grid Dashboard — UI-интерфейс управления задачами

## Стек

- Vite (сборщик)
- React
- TailwindCSS
- react-grid-layout
- localStorage для хранения состояния

## Описание проекта

**React Grid Dashboard** — это интерактивный интерфейс для постановки и управления задачами, реализованный в виде настраиваемой сетки. Пользователь может свободно перемещать задачи в пределах сетки с помощью drag-and-drop, а система сохраняет их расположение в `localStorage`, что обеспечивает персистентность макета между сессиями.

## Ключевые особенности

- **Гибкий drag-and-drop интерфейс** — задачи можно перетаскивать и изменять их размер в сетке.
- **Локальное хранилище** — координаты и размеры задач сохраняются автоматически в `localStorage`.
- **Универсальный layout** — реализован на основе `react-grid-layout`, что обеспечивает отзывчивость и расширяемость интерфейса.
- **TailwindCSS** — используется для быстрой стилизации и адаптивного дизайна.
- **Мгновенная разработка через Vite** — обеспечивает быструю сборку и горячую перезагрузку.
